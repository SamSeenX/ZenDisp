# SCOPE.md - Roadmap and Boundaries

## In-Scope

* Phase 1: Virtual display creation and teardown with preset resolutions (1600x900, 1080p, 1440p).
* Phase 2: ScreenCaptureKit live capture and Picture-in-Picture window with aspect-fit GPU scaling.
* Phase 3: Input wrapping, mouse coordinate translation, edge release, and space switch unwrap.
* Phase 4: Hardware DDC luminance control and software gamma dimming fallback.

## Out-of-Scope

* Cloud streaming or remote network transmission.
* Third-party UI frameworks like Electron, Qt, or React.
